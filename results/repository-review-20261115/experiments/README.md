# Rejected placement experiment

`sha3_oxide_elastic_reuse.tcl` attempted to retain name/type-matched primitive locations from the accepted original-adapter Oxide route. Vivado rejected conflicting packed LUT locations before placement. This is an archived experiment, not a supported build entry point and not a source of any deployed image. The final baseline uses medium spreading followed by post-route physical optimization; its source ledger and passing checks remain in the dated capture.
